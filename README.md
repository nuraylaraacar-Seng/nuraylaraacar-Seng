## 🚀 Featured Projects

### [Smart Wallet Backend](https://github.com/nuraylaraacar-Seng/smart-wallet)
A modular, concurrency-safe digital wallet API built with **Hexagonal Architecture (Ports & Adapters)** and **Domain-Driven Design (DDD)**.
**Highlights:**
* Deadlock-free pessimistic locking for concurrent mutual transfers
* Idempotency implementation to prevent double-spending
* Hybrid (Envelope) Encryption for sensitive user data (RSA + AES)
* Asymmetric RS256 JWT Authentication & Redis-backed rate limiting

### [Restaurant Reservation System](https://github.com/nuraylaraacar-Seng/Restaurant-Reservation-System)
A backend-focused reservation system with a clean layered architecture, designed for strict data consistency and stateless security.
**Highlights:**
* Database-level Pessimistic Locking to prevent double-booking
* RSA asymmetric key encryption for JWT signing
* Role-Based Access Control (RBAC) for endpoint authorization
* Automated exception handling and robust DTO mapping

### [Nexus HR AI](https://nexus-hr-ai.vercel.app)
An HR analytics platform that combines data processing, business analytics, and AI-assisted reporting.
**Highlights:**
* FastAPI-based backend architecture
* Dynamic dataset schema mapping with LLM support
* Redis-backed caching layer
* Secure file processing and validation
* Rate limiting and API protection
* Unit and integration testing with Pytest
